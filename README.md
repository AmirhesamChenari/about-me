# Taghdir-Me

وب‌سایت شخصی امیرحسام چناری با نام «تقدیر». این پروژه یک پورتفولیوی فارسی و راست‌چین است که حوزه‌های فعالیت، راه‌های ارتباطی، همکاری‌ها و مخزن‌های عمومی گیت‌هاب را نمایش می‌دهد.

## امکانات

- طراحی واکنش‌گرا با تم تیره و تأکید زرد
- نمایش معرفی و حوزه‌های فعالیت از تنظیمات JSON
- دریافت مخزن‌های عمومی از GitHub API و مرتب‌سازی بر اساس ستاره یا زمان به‌روزرسانی
- مدیریت همکاری‌ها از فایل JSON همراه با تصویر، لینک و توضیحات
- پیوندهای شبکه‌های اجتماعی و ایمیل
- پس‌زمینه‌ی تعاملی با پشتیبانی از تنظیمات کاهش حرکت سیستم
- پیاده‌سازی با HTML، CSS و JavaScript ساده؛ بدون چارچوب و بک‌اند

## اجرا

فایل‌های HTML و CSS مستقل‌اند، اما بارگذاری تنظیمات و اطلاعات همکاری‌ها با `fetch()` انجام می‌شود. بنابراین سایت را از طریق یک وب‌سرور استاتیک باز کنید؛ برای نمونه از افزونه‌ی **Live Server** در VS Code استفاده کنید. باز کردن مستقیم `index.html` با نشانی `file://` ممکن است مانع بارگذاری فایل‌های JSON شود.

پس از راه‌اندازی Live Server، صفحه‌ی `index.html` را باز کنید. برای انتشار نیز می‌توان فایل‌های پروژه را روی یک میزبان استاتیک مانند GitHub Pages قرار داد.

## ویرایش محتوا

- `site-settings.json`: عنوان صفحه، ایمیل، لینک‌ها و نام‌های کاربری شبکه‌های اجتماعی، متن معرفی، حوزه‌های فعالیت و پیام‌های بخش‌ها
- `collaborations.json`: فهرست همکاری‌ها. هر مورد می‌تواند `name`، `description`، `photo` و `link` داشته باشد. برای پنهان‌کردن یک مورد، مقدار `enabled` را `false` قرار دهید.
- `scripts/github.js`: دریافت مخزن‌ها از نشانی GitHub API مشخص‌شده در تنظیمات؛ برای نمایش مخزن‌ها، نام کاربری و نشانی API را در `site-settings.json` به‌روز کنید.

## ساختار پروژه

```text
.
├── assets/                  # نشان سایت
├── scripts/                 # رفتارهای جاوااسکریپت
├── styles/                  # استایل پایه، اجزا، بخش‌ها و واکنش‌گرایی
├── collaborations.json      # داده‌های همکاری
├── site-settings.json       # تنظیمات و محتوای سایت
└── index.html               # صفحه‌ی اصلی
```

## وابستگی‌ها

پروژه وابستگی زمان اجرای محلی ندارد. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای دریافت مخزن‌ها نیز مرورگر به اتصال اینترنت و دسترسی به GitHub API نیاز دارد.
